## Default Permission

Control and inspect the local cordn coordinator service

#### This default permission set includes the following:

- `allow-start`
- `allow-stop`
- `allow-status`
- `allow-config`
- `allow-diagnostics`
- `allow-request-battery-exemption`
- `allow-request-notification-permission`
